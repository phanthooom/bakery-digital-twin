# Навык: Верификация цифрового двойника (`verify-twin`)

Этот навык запускает полную проверку репозитория `bakery-digital-twin`, гарантируя целостность типов и отсутствие регрессий в логике.

## Команды проверки

1. **Запуск всех unit-тестов**:
   ```bash
   npm test
   ```
   Проверяет 200+ тестов на всех согласованных стыках (`packages/shared`, `web`, `simulator`).

2. **Проверка типов TypeScript**:
   ```bash
   npm run typecheck
   ```
   Проверяет конфигурации TypeScript во всех трех подпроектах (`packages/shared`, `simulator`, `web`).

## Критерии успешности
- Все тесты в `npm test` завершились со статусом `passed`.
- `npm run typecheck` завершился с кодом 0 без ошибок компиляции.
- Если обнаружена ошибка, субагент `engineer` обязан локализовать и устранить её до сдачи кода ревьюеру.
