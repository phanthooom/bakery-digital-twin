# Навык `ui-ux-pro-max`: Промышленный UI/UX, микроанимации и 3D-выноски

Используйте этот навык при создании или улучшении UI-компонентов в `web/src/ui/` и визуальных 3D-оверлеев в `web/src/scene/`.

## 1. Золотые правила UI для 3D-двойника (Taste & Impeccable UI)

1. **Сверка с `DESIGN.md`**:
   - Перед добавлением стилей проверьте токены в [`DESIGN.md`](file:///d:/bakery-digital-twin/DESIGN.md).
   - Карточки поверх 3D-сцены не должны перекрывать более 32% площади экрана на десктопе и 55% высоты на мобильном экране (Telegram Mini App).
2. **Иерархия данных в карточке (3 уровня)**:
   - **Уровень 1 (Герой)**: Название агрегата + бейдж статуса (`StatusIcon`) + главная метрика крупным шрифтом с `font-variant-numeric: tabular-nums` (используйте [`AnimatedNumber`](file:///d:/bakery-digital-twin/web/src/ui/AnimatedNumber.tsx)).
   - **Уровень 2 (Контекст)**: График истории за 6 часов или прогресс-бар загрузки номинала (`%`).
   - **Уровень 3 (Детали)**: Фазные токи (`A, B, C`), температура, влажность, автомат защиты и питающий фидер.
3. **Микроанимации (по Emil Kowalski)**:
   - Используйте `cubic-bezier(0.22, 1, 0.36, 1)` для появления карточек, тостов и шторок.
   - Аварийные состояния (`alarm` / `critical`) выделяйте мягким пульсирующим контуром, не вызывающим визуального шума.

## 2. Инженерные 3D-выноски (`DimensionalOverlay`)

- Для отображения архитектурных габаритов цеха, высотных отметок мезонина (`+3,200 м`) и габаритов выбранного станка используйте [`DimensionalOverlay.tsx`](file:///d:/bakery-digital-twin/web/src/scene/DimensionalOverlay.tsx).
- Все новые 3D-примитивы обязаны соблюдать бюджет draw-вызовов (объединение через `<MergeStatic>` с корректным массивом `deps`, отсутствие лишних `<pointLight>`).
