# ADR-0006: Газ — счётчик на вводе и три признака утечки

Статус: принято, 2026-10-09

## Контекст

Печи греются газом. Нужно видеть расход газа и вовремя заметить утечку. На вводе стоит один общий счётчик (на каждую горелку счётчики не ставят), в цехе — сигнализатор загазованности по метану.

## Решение

- **Счётчик газа на вводе** (импульсный выход → ESP32) даёт мгновенный расход, м³/ч, и накопленный объём по счётному механизму. Объём за период считаем по разнице показаний механизма, а не интегрированием расхода.
- **Ожидаемый расход** складываем по газовым станкам (`gasM3h` в `config/equipment.json`). Станок в работе (или в аварии) — номинал горелки × загрузка по электрическому счётчику. В простое горелка считается погашенной.
- **Утечка** — по трём признакам (`GasMonitor`, `packages/shared/src/gas.ts`):
  1. **Сигнализатор загазованности**: от порога 1 (10 % НКПР) — предупреждение, от порога 2 (20 %) — авария, сразу.
  2. **Расход при погашенных горелках** (`idleFlowM3h` дольше `idleMinutes`) — авария. Так видна и мелкая утечка, но только когда все горелки погашены: ночью, в перерыв.
  3. **Перерасход сверх ожидаемого** (больше `overPct` % и больше `overMinM3h`, дольше `overMinutes`) — предупреждение: утечка или неисправная горелка.
- Если хоть одна газовая печь «нет связи», горит ли её горелка — неизвестно. Признаки 2 и 3 тогда не срабатывают, работает только сигнализатор.
- Счётчик молчит дольше `offlineAfterSec` — «нет связи». Последние тревоги при этом остаются видны.

## Последствия

- Днём, когда печи горят, мелкая утечка (меньше разброса горелок) по расходу не видна: её ловит только сигнализатор. Ночью её ловит признак 2. Это ограничение одного счётчика на вводе.
- Программное выявление **не заменяет** сертифицированный сигнализатор загазованности с электромагнитным клапаном-отсекателем на вводе: по нормам они обязательны и должны перекрывать газ сами, без сервера. Двойник показывает и объясняет, но газ не перекрывает.
- Формат MQTT-сообщения счётчика газа пока не закреплён: сейчас данные идут только из мока (`GasSim`). Перед подключением ESP32 — дописать `docs/mqtt-contract.md` и тест `parseReading` (как для электричества).
