# ADR-0004: Сумма за энергию — по тарифу каждого часа, тарифы — история в конфиге

Статус: принято, 2026-10-08

## Контекст

Владельцу нужна стоимость энергии в сумах за смену, день и месяц. Тариф для юрлиц в Узбекистане меняется постановлениями (900 → 1 000 → 1 100 сум/кВт·ч с НДС в 2024–2026), для крупных потребителей (I группа) вводятся коэффициенты по зонам суток. Отчёт за прошлый месяц не должен «переоцениваться», когда выходит новый тариф.

## Решение

- Энергия копится журналом: кВт·ч каждого станка по часам (`EnergyLedger`).
- Тарифы — список с датой начала (`energy.tariffs`), опционально с зонами суток; цена часа = тариф на местную дату × коэффициент зоны.
- Сумма строки отчёта = Σ (кВт·ч часа × цена этого часа). Смены и зоны выровнены по целым часам, поэтому часового шага достаточно.
- Смены описаны в конфиге; ночная смена относится к дате начала.

## Последствия

- Новый тариф — новая строка в конфиге; прошлые периоды считаются по старым ценам.
- Граница зоны или смены не на целом часе потребует журнала с шагом 15–30 мин.
- Сумма покрывает только станки под мониторингом; общий счёт по вводному счётчику цеха — отдельная задача.
