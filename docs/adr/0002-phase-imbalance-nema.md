# Несимметрия фаз — по NEMA (по действующим токам), а не через обратную последовательность

Счётчики на ESP32 (PZEM/SDM) отдают только действующие значения токов без фазовых углов, поэтому коэффициент несимметрии по обратной последовательности (IEC/ГОСТ) посчитать нельзя. Берём определение NEMA MG-1: наибольшее отклонение тока фазы от среднего, делённое на среднее. Оно совпадает с цифрами из референсного демо (1,03/2,25/0,24 А → 92 %). Аварией несимметрия считается только под нагрузкой (≥ 30 % номинала), потому что на холостом ходу однофазные потребители внутри станка дают большой, но безвредный перекос.
