## Принципы
- Конфиг оборудования — единственный источник правды (`config/equipment.json`), его читают симулятор, API и (через API) web.
- Логика расчётов — чистые функции в `packages/shared`, покрытые тестами; сервисы только «склеивают» ввод-вывод.
- Симулятор и реальный ESP32 взаимозаменяемы: один и тот же топик и формат JSON.
- После каждого рабочего шага — запуск, проверка, `git commit`.

## Вне рамок первой итерации
- Встраивание 3D-сцены в Grafana (панель-плагин или iframe).
- Реальные GLB-модели станков, аутентификация, TLS для MQTT, алерты в Telegram.
