# 01: Живые показания симулятора в 3D-сцене

**What to build:** Оператор открывает сцену в режиме живых данных и видит показания, которые симулятор публикует в MQTT: статусы, карточка и светофоры обновляются так же, как в демо-режиме. Появляется сервис API, который подписан на показания, ведёт состояние станков тем же движком двойника и отдаёт его фронту (снимок + поток обновлений); фронт получает второй источник данных, переключаемый настройкой.

**Blocked by:** None (can start immediately)

**Status:** needs-triage

- [ ] При запущенных брокере, симуляторе и API сцена в режиме живых данных показывает все 8 станков со статусами
- [ ] Остановка симулятора через 30 с переводит станки в «Нет связи»
- [ ] Демо-режим продолжает работать без брокера и API
- [ ] Тесты на стыке API: показание из MQTT → состояние станка в снимке
