# Планы и состояние задач (Multi-Agent Task Plans)

В этой директории фиксируются промежуточные и финальные планы реализации задач, выполняемых оркестром ИИ-агентов Antigravity (`architect`, `engineer`, `code-reviewer`) под управлением Мастер-Оркестратора.

## Жизненный цикл статусов

- **`DRAFT`**: План формируется архитектором (`architect`), идёт сбор требований и анализ архитектурных стыков.
- **`READY_FOR_DEV`**: План согласован, декомпозирован на TDD-стыки и готов к передаче инженеру (`engineer`).
- **`IN_PROGRESS`**: Инженер реализует функционал и тесты.
- **`REVIEW`**: Изменения переданы на аудит субагенту `code-reviewer`.
- **`COMPLETED`**: Ревью пройдено (`APPROVED`), все тесты и проверки типов завершены успешно.

## Шаблон плана

Для создания нового плана скопируйте [template.md](file:///d:/bakery-digital-twin/plans/template.md) и заполните его по разделам. Именуйте файлы в формате:
`plans/YYYY-MM-DD-<краткое-описание>.md`
